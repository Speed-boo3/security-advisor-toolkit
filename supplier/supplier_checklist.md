## Documentation and certification

- [ ] ISO 27001 certificate or equivalent (copy requested)
- [ ] Data processing agreement signed
- [ ] Security requirements documented in the contract
- [ ] Breach notification clause in place (target: 24 hours)
- [ ] Right-to-audit clause accepted

## Access and personnel

- [ ] Principle of least privilege applied to access granted
- [ ] Personnel background checks conducted for relevant roles
- [ ] Security awareness training completed by supplier staff
- [ ] Named contact for security incidents identified

## Technical controls

- [ ] Data encrypted in transit and at rest
- [ ] Patch management and vulnerability handling process in place
- [ ] Incident response procedure documented and tested
- [ ] Subcontractor arrangements require prior written approval

## Supply chain and resilience

- [ ] Subcontractors subject to equivalent security requirements
- [ ] Business continuity capability demonstrated
- [ ] Software bill of materials (SBOM) available for critical software
