# Changelog

## v1.0.0 -- September 2026

Initial release.

- Risk assessment tool following NSM VSR methodology and ISO 27001:2022
- Supplier security assessment against Annex A 5.19-5.22 (14 criteria)
- ISO 27001:2022 gap analysis across 24 controls and 4 themes
- Compliance report generator with NIS2, DORA and AI governance sections
- Security policy template with NIS2 and NSM requirements
- Supplier security contract clause library (7 clauses)
- Sample risk register with 8 realistic scenarios
